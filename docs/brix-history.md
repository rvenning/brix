# BRIX — history

## BRIX 1.00 (1991)

Written by Michael Riedel, a computer science student in Karlsruhe, in October 1991
"to fill" six weeks between exams by practising VGA programming (from `BRIX.DOC`).
The title screen credits "RADIESEL PRESENTS" and thanks Jürgen Egeling for some of the
levels and Rainer Stober for technical support. It was released into the public domain,
with a request for voluntary payment.

It is a Puzznic-style game (Taito, 1989): blocks are pushed sideways and fall, and
touching blocks of the same kind vanish. BRIX 1.00 has 112 problems arranged in a
7-level tree of choices, a per-problem time limit, retries, continues, a two-player
alternating mode, and one mechanic beyond gravity: the elevator.

The copy this project is built on is the 1.00 release preserved in `reference/brix100/`
(see [legal-notes.md](legal-notes.md)).

## Later versions (not used by this project)

According to Wikipedia, an updated version with enhanced graphics and sound was published
by Epic MegaGames in 1992, alongside **Brix 2 Deluxe**, which added new levels, a level
editor and further mechanics such as lasers, reversing gravity, teleporters, breakable
barriers and acid. Those mechanics are **not** part of BRIX 1.00: its executable only
knows blocks, walls and one elevator per problem (see [brix-mechanics.md](brix-mechanics.md)).
A later title, *Brix 3: Superlogic*, is outside this project's scope.

None of the later releases' levels, art, sound or code are used here; their licensing
is not assumed to be public domain.
